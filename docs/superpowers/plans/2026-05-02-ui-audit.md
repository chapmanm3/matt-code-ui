# UI Audit — High-Contrast Minimal Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Redesign the app's visual identity from a generic VS Code–style dark theme to a high-contrast minimal aesthetic with near-black backgrounds, pure white active states, and no color accents.

**Architecture:** All changes are CSS-only or small TypeScript tweaks in `src/main.ts`. No new files are created. The five tasks are independent and can be committed separately — each leaves the app in a working state.

**Tech Stack:** Tauri 2, vanilla TypeScript, Vite, xterm.js. Type-check with `npm run build`. Run the app with `npm run tauri dev`.


Find the `toggleTerminal()` function and replace the three `toggleBtn.textContent` assignments with `innerHTML`:

```typescript
function toggleTerminal() {
  const container = document.getElementById("terminal-container");
  const mainContent = document.getElementById("main-content");
  const toggleBtn = document.getElementById("toggle-terminal");
  if (!container || !toggleBtn) return;

  if (container.classList.contains("collapsed")) {
    container.classList.remove("collapsed");
    container.classList.remove("full-height");
    if (mainContent) mainContent.style.display = "";
    toggleBtn.innerHTML = ICON_CHEVRON_DOWN;
    setTimeout(() => getActiveTab()?.fitAddon?.fit(), 100);
  } else if (container.classList.contains("full-height")) {
    container.classList.remove("full-height");
    if (mainContent) mainContent.style.display = "";
    toggleBtn.innerHTML = ICON_CHEVRON_DOWN;
    setTimeout(() => getActiveTab()?.fitAddon?.fit(), 100);
  } else {
    container.classList.add("collapsed");
    container.classList.remove("full-height");
    toggleBtn.innerHTML = ICON_CHEVRON_RIGHT;
  }
}
```
